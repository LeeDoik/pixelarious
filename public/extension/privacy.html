STARFALL DRIFT — 크롬 확장 개인정보 처리방침

최종 수정일: 2026-08-22

STARFALL DRIFT 크롬 확장(이하 "본 확장")은 어떠한 개인정보도 수집·저장·전송하지 않습니다.

수집하지 않는 항목

  • 개인 식별 정보(이름, 이메일, 주소 등)
  • 건강·금융 정보
  • 인증 정보(비밀번호, 쿠키, 토큰 등)
  • 개인 통신 내용
  • 위치 정보
  • 방문 기록, 열람 중인 웹페이지의 내용
  • 사용 통계·분석·텔레메트리

동작 방식

본 확장은 사이드 패널에 www.pixelarious.online의 게임 페이지를 불러오는 껍데기입니다. 권한은 사이드 패널을 여는 sidePanel 하나만 요청하며, 호스트 권한이나 콘텐츠 스크립트가 없어 사용자가 방문하는 웹페이지를 읽거나 변경할 수 없습니다.

게임 진행 상황(최고 점수 등)은 브라우저 내부 저장소(IndexedDB)에만 저장되며 기기를 떠나지 않습니다. 게임 파일을 내려받는 과정에서 웹 서버에 일반적인 접속 기록(IP 주소 등)이 남을 수 있으나, 이는 웹사이트를 브라우저로 여는 것과 동일한 수준이며 본 확장이 별도로 수집하는 정보는 없습니다.

제3자 제공

수집하는 정보가 없으므로 제3자에게 판매·양도·공유하는 정보도 없습니다.

STARFALL DRIFT — Chrome Extension Privacy Policy

Last updated: 2026-08-22

The STARFALL DRIFT Chrome extension ("the extension") does not collect, store, or transmit any user data.

Data we do not collect

  • Personally identifiable information (name, email, address)
  • Health or financial information
  • Authentication information (passwords, cookies, tokens)
  • Personal communications
  • Location
  • Browsing history or the content of pages you visit
  • Usage analytics or telemetry

How it works

The extension is a thin shell that loads the game page from www.pixelarious.online inside the Chrome side panel. It requests a single permission, sidePanel. It declares no host permissions and no content scripts, so it cannot read or modify the pages you browse.

Game progress (such as your high score) is kept in the browser's local IndexedDB storage and never leaves your device. Loading the game makes an ordinary web request to the site, which may appear in standard server logs — the same as opening the website in a tab. The extension itself collects nothing.

Third parties

No data is collected, so no data is sold, transferred, or shared with third parties.
