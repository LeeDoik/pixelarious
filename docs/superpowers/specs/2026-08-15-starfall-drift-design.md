# STARFALL DRIFT — 게임 설계

**날짜:** 2026-08-15
**상태:** 사용자 질답으로 확정된 설계 (구현 플랜의 입력)
**대상:** NEO_KIDO 카트리지 `starfall-drift` (현재 플레이스홀더 → 실제 게임으로 교체)

## 1. 컨셉

별똥별이 쏟아져 내리는 하늘을 거슬러, 붕괴하는 별들을 갈아타며 위로 표류하는 **원버튼 궤도 호핑 아케이드**.

- 조작은 탭 하나. 모바일(터치)과 PC(스페이스/클릭)에서 동일한 경험
- 엔드리스 스코어 어택 — 죽으면 2초 안에 재도전하는 "한 판 더" 루프
- 잡은 별은 그 순간부터 붕괴하기 시작한다. 머무르기 vs 서두르기 판단이 매 순간의 긴장

## 2. 코어 루프와 조작

1. 별 주위를 자동 공전한다. 공전 시작 순간부터 그 별의 붕괴 게이지가 차오른다(별이 흔들리고 조각이 떨어져 나감)
2. **탭** → 접선 방향으로 이탈. 이탈 후에는 약한 하방 중력을 받는 포물선 비행
3. 다른 별의 궤도 원(포획 반경 = 궤도 반경) 안에 들어오면 자동으로 그 별의 궤도에 스냅 진입. 공전 방향은 진입 시 접선 성분 부호를 따른다
4. 위로 갈아타며 고도를 올린다. 카메라는 플레이어 상승만 따라간다(아래로는 안 내려감)
5. 좌우 화면 가장자리는 보이지 않는 벽 — 비행 중 닿으면 탄성 반사(수평 속도 반전, 감쇠 0.9). 죽지 않는다

입력: `InputEventScreenTouch`(화면 아무 데나), `Space`, 마우스 좌클릭 — 전부 동일한 "액션" 하나.

## 3. 엔티티

| 엔티티 | 크기(스프라이트) | 궤도 반경 | 공전 속도 | 붕괴 시간 | 비고 |
|---|---|---|---|---|---|
| ★ 표준성 | 32px | 28px | 2.4 rad/s | 3.5s | 기본 별 |
| · 왜성 | 16px | 16px | 3.6 rad/s | 2.0s | 작고 빠름, 경유 보너스 +50 |
| ✦ 거성 | 48px | 44px | 1.6 rad/s | 6.0s | 쉬어가는 별 |
| ⚙ 소행성 | 24px | — | — | — | 등속 이동(직선/사인), 접촉 즉사. 고도 300m부터 등장 |

수치는 전부 시작값이며 플레이테스트로 튜닝한다. 별 붕괴가 완료되면 별은 파편 파티클과 함께 소멸한다.

## 4. 죽음 조건 (2가지) — 2026-08-15 플레이테스트 개정

1. 아무 별도 잡지 못하고 화면 하단 밖으로 낙하
2. 소행성 접촉

공전 중인 별이 완전 붕괴하면 **즉사가 아니라 낙하**한다: 그 순간의 공전 관성(접선 속도)을 안고
FLYING 상태로 전환되어 중력으로 떨어지며, 아래쪽 별의 궤도에 잡히면 생존(구조)한다.
화면 밖까지 떨어지면 1번 규칙으로 사망. (개정 전에는 붕괴 = 즉사였음)

죽음 → 즉시 슬로모+파편 연출(0.5s) → 스코어/베스트 화면 → 탭 한 번으로 재시작.

## 5. 스코어링

- **고도**: 상승 10px = 1m. 기본 점수 = 도달 고도(m)
- **스위프트 호핑**: 붕괴 게이지 30% 이내에 이탈하면 콤보 +1 (배수 ×2…×5 상한). 게이지 30%를 넘겨 이탈하면 콤보 리셋. 보너스 = 25 × 현재 배수
- **왜성 경유 보너스**: +50
- 최종 점수 = 고도 + 보너스 합산. 로컬 베스트는 `user://`에 저장(웹에서는 IndexedDB로 영속)

## 6. 난이도 곡선

고도 기반 파라미터 커브(순수 함수, 시드 주입 가능):

- 별 세로 간격: 90px → 140px로 점증
- 타입 확률: 시작 30초(~150m)는 표준성·거성 위주 → 고도가 오를수록 왜성 비율 증가
- **붕괴 유예: 500m까지는 별이 아예 붕괴하지 않는다**(2026-08-22 개정). 도입부에서 조작·궤도 감각을 익히는 구간으로, 균열·흔들림·경고음도 함께 꺼진다. 500m를 넘긴 지점에서 생성된 별부터 붕괴가 시작된다
- 붕괴 속도 배율: 고도에 따라 최대 1.5×
- 소행성 밀도: 300m부터 서서히 증가
- **도달 가능성 보장**: 생성기는 어떤 고도에서도 "현재 별에서 물리적으로 도달 가능한 별이 최소 1개" 조건을 검증한다(단위 테스트 대상)

## 7. 세션 흐름과 UI

- 타이틀: 로고 + "TAP TO DRIFT" (첫 조작이 곧 튜토리얼 — 첫 별은 안전한 거성)
- 플레이 HUD: 상단에 고도(m)와 콤보 배수만. 최소주의
- 게임오버: SCORE / BEST / "TAP TO RETRY". 죽음→재시작 2초 이내
- 창/탭 포커스를 잃으면 자동 일시정지(PAUSED 오버레이, 탭으로 재개) — 모바일 탭 전환 대응
- UI 라벨은 영어 아케이드 관용구, 폰트는 Galmuri(사이트·LAST LOGIN과 동일 계열)

## 8. 비주얼·오디오

- 카트리지 커버와 동일한 PICO-8 밤하늘 팔레트: 하늘 `#0C0A1C`, 원경 `#1D2B53`, 별빛 `#FFF1E8`, 하이라이트 `#FFEC27`, 플레이어 핑크 `#FF77A8`, 보조 시안 `#29ADFF`
- 기준 뷰포트 **270×480 (9:16 세로)**, `canvas_items` 스트레치, 세로 expand — 폰 화면비(18~20:9)에서는 상하 시야가 조금 더 보이는 방식
- 배경: 아래로 흐르는 별똥별 파티클 레이어(패럴랙스 2겹) — "쏟아지는 별을 거슬러 오른다"는 그림
- **에셋은 PixelLab 생성 우선(퀄리티 우선)**: 플레이어(표류자 idle/비행/사망), 별 3종 × 붕괴 4단계, 소행성(회전), 타이틀 로고, 성운 소품. 생성 후 커버 팔레트 톤으로 후처리. API 키는 `.env.local`의 `PIXELLAB_API_KEY`(gitignore됨, 잔액 $10 확인)
- SFX: `scripts/gen_audio.py` 방식 확장(파이썬 합성 칩튠) — 호핑, 포획, 붕괴 경고, 사망, 콤보 상승. 가벼운 앰비언트 루프 BGM

## 9. 기술 아키텍처

**리포 재편**
- `game/` → `games-src/last-login/` 이동, `export_presets.cfg`의 export_path를 `../../public/games/last-login/index.html`로 수정, README·.gitignore 경로 갱신
- 신규 `games-src/starfall-drift/` — Godot 4.7.1 Standard(GDScript), gdUnit4 하네스 동일 패턴 (`$GODOT = C:\Users\LeeDoik\tools\godot\godot_console.exe`)

**Godot 구조 (starfall-drift)**
- 오토로드: `GameState`(점수/베스트/세션 상태), `Sfx`(사운드 재생)
- 씬: `Main`(타이틀→플레이→게임오버 상태 머신), `Player`, `Star`(타입은 파라미터 리소스 — 씬 하나), `Asteroid`, `Starfield`(배경), `HUD`
- **물리 엔진 미사용, 커스텀 키네마틱**: 공전 각도 적분, 접선 이탈 벡터, 하방 중력 포물선, 원형 포획 판정. 수학은 `src/core/orbit_math.gd`, `src/core/spawner.gd`, `src/core/scoring.gd` 순수 함수로 분리
- 웹 익스포트: Web 프리셋, 스레드 비활성화(COOP/COEP 불필요), `web/shell.html` 재사용 + 모바일 뷰포트/터치 점검 → `public/games/starfall-drift/`

**사이트 등록**
- `content/games/01-starfall-drift.json`: `playPath: "/games/starfall-drift/index.html"`, 태그 교체(`GODOT 4`, `2D`, `ARCADE`, `ONE BUTTON`, `MOBILE OK`), 소개문을 확정 기획 기준으로 갱신
- play 페이지에서 세로 캔버스 모바일 임베드 확인

## 10. 테스트 전략

- gdUnit4 단위 테스트(헤드리스): `orbit_math`(접선 벡터·포획 판정·진입 방향), `spawner`(고도별 확률 커브, 도달 가능성 보장), `scoring`(콤보 배수·리셋·보너스)
- 사이트 vitest 기존 스위트 통과 확인(games.ts 스키마)
- 수동 플레이테스트 체크리스트: `docs/superpowers/specs/starfall-drift-playtest.md` — 데스크톱 크롬/파이어폭스 + 모바일 크롬/사파리(실기), 터치 반응·30fps 이상·재시작 루프·베스트 영속 확인

- 모바일 브라우저(안드로이드 크롬, iOS 사파리)에서 터치만으로 온전히 플레이 가능
