# IT SLEEPS BELOW — 게임 설계

**날짜:** 2026-08-15 (공포 컨셉 심화 반영: 같은 날 2차 질답)
**상태:** 사용자 질답으로 확정된 설계 (구현 플랜의 입력)
**대상:** NEO_KIDO 카트리지 (현재 `down-the-cave` 플레이스홀더 → 실제 게임으로 교체)
**제목:** **IT SLEEPS BELOW — 아래에 잠든 것** (구 가제 DOWN THE CAVE에서 사용자 선정으로 변경. 슬러그·경로·JSON 파일명도 `it-sleeps-below`로 통일)

## 1. 컨셉

곡괭이와 램프 하나로 내려가는 **왕복 채굴 로그라이크 호러**.

> 내려가는 건 쉽다. 문제는 올라오는 것이다.

- 카트리지 소개문("램프 기름이 떨어지기 전에 돌아올 수 있을까요?")이 그대로 게임의 정체성
- 전투 없음 — 공포는 분위기와 회피형 위협으로만. 점프스케어 없이 서서히 조여오는 드레드, 충격 연출은 최심부 엔딩 한 곳만 허용
- 모바일 필수 · 세로 화면 · 탭 조작 (NEO_KIDO 모바일 원칙 유지)

## 2. 코어 루프 (한 런)

1. **하강** — 지표 거점에서 출발. 인접 타일을 탭하면 판다/이동한다. 중력이 있어 아래로는 빠르다
2. **채굴** — 광석을 캐서 가방에 담는다 (슬롯 1개 = 광석 1개). 깊을수록 비싼 광석
3. **복귀** — 파낸 통로는 런 동안 그대로 남는다. 위로는 벽을 짚고 기어올라야 하며 하강보다 느리다 — **상승 시간 ≈ 하강의 2배** (튜닝 목표). 이 비대칭이 "돌아갈 수 있을까?"를 시스템으로 만든다
4. **정산** — 살아서 지상에 도착해야 광석이 골드로 확정. 죽으면 가방은 죽은 자리에 남는다(§4 유품 회수). 은행 골드·업그레이드는 유지 — 로그라이트

맵은 런마다 시드를 바꿔 재생성한다. 폭 16타일 고정, 좌우 경계는 파괴 불가 경계석.

## 3. 램프 경제 — 기름 = 시간 = 안전

- 기름은 램프가 켜진 동안 실시간으로 탄다. 잔량 단계에 따라 **빛 반경이 계단식으로 좁아진다**
- **램프 스위치**: 램프는 수동으로 켜고 끌 수 있다 (모바일: HUD 램프 버튼, PC: `Space`). 끄면 기름 소모 0, 시야는 플레이어 주변 1타일의 희미한 잔광뿐
- 빛은 시야이자 방어다: '그것'은 빛 안에서 움직이지 못한다(§6). **켜면 그것이 멈추지만 기름이 타고, 끄면 기름은 아끼지만 그것이 움직인다** — "켤까 끌까"의 대치가 이 게임 공포의 심장. 기름 게이지가 곧 공포 게이지
- **숨죽이기**: 입력 없이 정지해 있으면 소리를 내지 않는다. 램프를 끄고 숨죽이면 그것은 마지막 감지 지점만 보고 움직이다 지나쳐 간다
- 기름 소진 = 즉사가 아니라 최악의 생존 — 한 치 앞 어둠 속에서 기어 올라가는 이 구간이 공포의 절정
- 갱도에서 드물게 기름 병 픽업(+25%, 빈도는 튜닝). 런 시작 시 항상 만땅

## 4. 죽음 조건

| 원인 | 결과 |
|---|---|
| 3타일 초과 낙하 (장화로 완화) | 하트 1 데미지 |
| 금 간 타일 붕괴·낙석 | 하트 1 데미지 |
| '그것'에게 잡힘 | 즉사 |
| 하트 소진 | 사망 → 가방은 그 자리에 남고, '다음 광부'가 지표에서 눈뜸 |

전투는 없다. 곡괭이는 오직 땅을 판다.

**죽음의 서사 — 다음 광부와 유품 회수:**
- 죽은 광부는 산에 먹힌다. 다음 런의 주인공은 **'다음 광부'** — 상인이 데려온 다음 고용인(§8)
- **유품 회수**: 다음 런의 맵 생성 시 죽은 깊이 근처에 유품 가방을 배치. 회수하면 내용물이 현재 가방에 들어온다 (슬롯 초과분은 바닥에 남음)
- 유품 근처에는 **직전 광부였던 그것**이 배회한다 — 내 가방을 지키는 건 어제의 나. 외형에 직전 광부의 흔적(장비·가방 실루엣)
- 유품은 최근 1개만 유지 — 새로 죽으면 이전 유품은 소멸한다 (산이 소화)

## 5. 지층 (깊이 커브 = 공포 커브, 수치는 시작값)

| 깊이 | 지층 | 광석 | 분위기 | 위협 |
|---|---|---|---|---|
| 0–40m | 표토 | 석탄·구리 | 밝은 흙, 지상의 빛, 새소리가 멀어짐 | 없음 (튜토리얼 지대) |
| 40–120m | 암반 | 철·은 | 물방울 소리, 짙어지는 어둠 | 낙석·금 간 타일. 첫 이상 현상(미묘하게) |
| 120–240m | 균열대 | 금·자수정 | 벽의 긁힌 자국, 버려진 장비 | 붕괴 잦아짐. '그것'의 기척(§6 스테이징 ①) |
| 240–400m | 심층 | 발광 광석 | 유기적 질감, 맥동하는 발광, BGM 소거 | **'그것' 실체 배회** (§6 스테이징 ②③) |
| 400m | 최심부 | — | 엔딩 챔버 (§9) | — |

지층 경계는 곡괭이 레벨로 게이트한다(§10). 지층 진입 시 지층 이름이 잠깐 표시된다.

**지상 오염**: 세이브의 최고 도달 깊이에 따라 거점도 단계적으로 변한다 — 하늘 색이 탁해지고, 새소리가 줄고, 거점 음악의 음정이 미세하게 틀어지고, 상인의 행동이 조금씩 이상해진다. 안전지대가 서서히 안전하지 않게 느껴지는 것이 '조여오는 공포'의 마지막 단계. 오염 단계는 지층 게이트와 동기화하고, 단계별 연출 목록은 구현 플랜에서 확정.

## 6. '그것' (Lurker)

**정체 — 설계 노트 (게임 내 직접 설명 금지, 모든 연출의 일관성 기준):**
산은 살아있는 유기체다. 너무 깊이 파고들어온 전임 광부들을 소화해 자신의 **면역체계**로 만들었다. 그것들이 광부의 실루엣인 이유, 곡괭이 소리를 흉내 내는 이유, 심층의 질감이 유기적인 이유, 최심부에 심장이 있는 이유가 전부 여기서 나온다. **로어 일지의 작성자들이 곧 플레이어가 마주치는 그것들이다(§8).**

**행동 규칙:**
- **빛 안에서는 완전 정지. 어둠 속에서만 다가온다.** AI는 이것이 전부
- 이동은 파낸 공간으로만 — **네가 판 길이 그것의 길이다**
- 채굴 소리에 반응해 목표 지점을 갱신한다 (캘수록 가까워진다 — 욕심의 대가)
- 램프가 꺼진 동안은 마지막으로 빛·소리를 감지한 지점으로 이동 후 배회. 플레이어가 숨죽이면(§3) 지나쳐 간다
- 닿으면 즉사. 처치·격퇴 불가. 동시 활성 최대 1개체(피날레 제외)

**파도형 디렉터 (압박 리듬):**
- 그것의 활동은 사이클을 탄다: **사냥**(추적, 심박 고조) → **퇴장**(멀어짐) → **침묵**(비활성 — 파밍에 집중할 수 있는 창) → 다시 사냥
- 침묵이 있어야 다음 파도가 무섭다. 플레이어는 리듬을 읽으며 "지금이야" 타이밍을 재게 된다
- 깊이가 깊어질수록 침묵 구간이 짧아진다 (수치는 튜닝). 디렉터 상태는 `lurker_logic` 순수 함수에 포함 (테스트 대상)

**등장 스테이징 (3단):**
1. **균열대 — 기척만**: 빛 가장자리를 스치는 실루엣 목격 1회 (스크립트, 실체 없음)
2. **심층 첫 진입 — 스크립트 조우**: 첫 실체 조우를 설계된 상황에서 — 도망칠 길이 보장된 통로에서 규칙(빛=정지)을 몸으로 배우게 한다
3. **이후 — 완전 절차적 배회**: 시스템이 공포를 만든다

**연출 조우 풀 (세이브당 각 1회, 절차 배회와 별개로 발동):**
- 통로 끝에 등을 보이고 서 있다 — 빛을 비추면 벽 속으로 스며든다
- 내가 캐다 만 광석 앞에서 소리 없이 곡괭이질을 흉내 내고 있다
- 벽 한 겹 너머에서 내 발걸음과 나란히 걷는 소리
- **저 아래 갱도에서 램프 불빛 하나가 천천히 올라온다** — 그것들도 램프를 들고 있다. *"갱도에서 다른 불빛을 보면, 그것은 광부가 아니다"* (로어 일지의 경고와 연결)

## 7. 이상 현상 (AnomalyDirector)

절차 생성 위에 얹는 수작업 연출 풀. 깊이·조건 트리거, **대부분 세이브당 1회** (반복되면 공포가 죽는다). 지층별로 강도를 높여 배치하고, 데이터 주도 구조로 이벤트 추가가 쉽게.

**다이제틱 (게임 세계 안의 사건):**
- 램프가 2초 꺼졌다 켜진다. 아무 일도 없다 (처음엔)
- 파고 내려온 통로가 등 뒤에서 메워져 있다
- 곡괭이질 에코가 한 박자 늦게 두 번 울린다
- 화면 가장자리를 실루엣이 지나간다 (빛 밖에서)
- 캐낸 광석 자리에서 속삭임이 들린다
- 지상 상인이 자리에 없고 메모만 있다 (다음 런에 복귀)
- 판 적 없는 옆 통로가 생겨나 있다 — 끝에는 전임 광부의 유품(§8)
- 곡괭이질을 멈췄는데 어디선가 같은 리듬의 곡괭이 소리가 두어 번 더 이어진다
- 지나쳐 온 광석 타일이 다시 메워져 있고 광석은 없다
- 가짜 심박 — 그것이 근처에 없는데 심박 사운드가 잠깐 고조된다
- 심층 도달 이후: 지상으로 복귀한 순간 하늘이 1초간 검다

**가벼운 메타 (HUD의 거짓말 — 게임 캔버스 안 한정):**
- 깊이계가 순간 `999m`를 찍고 돌아온다
- 분명히 올라가는데 깊이 숫자가 몇 초간 늘어난다
- 램프 게이지가 0으로 보였다가 실제값으로 복귀한다
- 가방에 캔 적 없는 '검은 광석'이 있다 — 확인하려 하면 사라진다
- 일시정지 화면의 `PAUSED`가 아주 잠깐 `나가지 마`로 읽힌다

**후반 실체화**: 초중반의 이상 현상은 절대 해치지 않는다 — 플레이어가 "이건 연출이다"를 학습하게 둔다. 심층·지상 오염 후반부터 일부가 실제가 된다: 램프 소등이 그것의 접근 타이밍과 겹치고, 메워진 통로가 진짜로 경로를 바꾼다. 학습된 안전감의 배신이 최종 단계의 공포. 단, 실체화가 즉사로 직결되지는 않게 설계한다 (억울함 방지).

**금지선**: 가짜 크래시, 세이브 삭제 위장, 브라우저/OS UI 흉내는 절대 금지. 게임 세계의 계기반(HUD)까지만 거짓말할 수 있다.

## 8. 로어 시스템 — 광부 일지와 흔적

전달 채널: **광부 일지(텍스트) + 기록물·유품 오브젝트 + 벽·지형지물** 3중.

- **일지 시리즈**: 전임 광부 3~4명. 각자의 일지가 깊이 순으로 발견된다 — 하강 기록이 점점 이상해지다 끊긴다. 각 시리즈의 마지막 일지는 항상 미완이고, **그 근처엔 그것이 배회한다 (작성자다)**
  - 예시 설계: ① 신중한 선배 — 생존 규칙을 남긴다 ("불빛을 봐도 부르지 마라") ② 탐욕에 먹힌 자 — 더 깊이, 더 많이 ③ 산의 정체에 다가간 학자 — 심장의 존재를 기록
- **수첩**: 주운 일지는 거점 수첩에서 다시 읽기 가능. 수집률 표시 — 은근한 수집 목표이자 서사 밀도
- **환경 스토리텔링**: 버려진 텐트, 부러진 사다리, 반쯤 묻힌 장화, 벽의 "돌아가" 긁힘 — 일지 작성자들의 흔적으로 배치해 텍스트와 오브젝트가 같은 이야기를 가리키게 한다
- **상인 — 설계 노트 (게임 내 직접 설명 금지)**: 산과 거래하는 모집자. 산은 광부(먹이)를 얻고 상인은 광석을 얻는다. 플레이어는 그의 최신 고용인이고, '다음 광부'(§4)는 그의 다음 공급이다. 지상 오염 단계(§5)마다 상인의 이상함이 이 비밀의 단서가 되며 — 대사가 아니라 행동·소품 변화로 — 코즈믹 리빌 직전 마지막 퍼즐 조각이 된다
- 서사 텍스트는 **한국어 + 영어 토글**(§12). 일지 1장 = 화면 하나 분량(3~6줄), 읽기는 탭으로 닫는 오버레이. 텍스트는 코드와 분리된 데이터 파일(ko/en 키 쌍)로 관리

## 9. 엔딩 — 산의 심장과 코즈믹 리빌

- 400m 최심부 챔버 중앙에 맥동하는 거대 발광 광석 **'산의 심장'**
- 심장을 캐는 순간 (유일하게 허용된 충격 연출) 모든 빛이 죽고 산 전체가 깨어난다
- **피날레**: 심장의 맥동이 유일한 광원 — 펄스가 밝아지는 동안만 그것들이 멈춘다. 깨어난 그것들 사이로 400m를 기어오르는 원테이크 탈출
- **탈출로 = 내 통로 + 산의 뒤틀림**: 기본은 파밍 중 내가 판 길 그대로 ("네가 판 길이 네 운명이다"). 단, 산이 깨어나며 곳곳을 뒤튼다 — 오를 수 없는 수직갱엔 붕괴 경사로가 생기고, 일부 구간은 막혀 우회를 강제. 지형 변형 후 도달 가능성은 검증 로직으로 보장 (단위 테스트 대상)
- **코즈믹 리빌 (진엔딩)**: 지상으로 나온 순간 카메라가 뒤로, 위로 끝없이 줌아웃 — **산 하나가 아니다.** 지평선까지 이어진 산맥 전체가 같은 리듬으로 숨쉬고, 봉우리마다 심장의 맥동 불빛이 별처럼 박혀 있다. 플레이어가 들고 나온 것은 '심장'이 아니라 심장 *하나*. 자막 한 줄 — *"네가 판 것은 산이 아니라, 잠든 것의 살갗이었다."* — 그리고 크레딧. 설명은 여기까지, 해석은 플레이어의 몫 (선택지·교훈 없음, 스케일의 자각으로 종료)
- **마지막 유혹**: 탈출로 곳곳에 최고가 광석이 반짝인다. 캘 수 있다 — 소리가 나고 그것들이 반응한다. 살아 나가면 그대로 정산. "캘수록 그것이 가까워진다"는 게임 전체의 규칙이 절정에서 가장 잔인한 형태로 돌아온다
- 피날레 실패 → 산은 다시 잠들고 지표에서 눈뜸, 다음 런에서 재도전 가능
- 크레딧 후: 거점으로 복귀해 자유 플레이 유지 (일지 수집 완성 등). 뉴게임+ 없음

## 10. 이코노미·업그레이드 (시작값, 튜닝 대상)

광석 가치: 석탄 5 / 구리 10 / 철 25 / 은 50 / 금 100 / 자수정 150 / 발광 광석 300 G

## 11. 조작

- **인접 4방향 타일 탭** — 벽이면 판다, 빈 곳이면 이동. **길게 누르면 연속 동작**. 비인접 탭은 무시
- **조심 채굴**: 길게 누르는 연속 채굴은 빠르지만 시끄럽고, 한 번씩 끊어 파면 느리지만 조용하다 (§6 소리 반응과 연동). 소음 수치는 HUD에 표시하지 않는다 — 소리 자체가 피드백
- **램프 토글** — 모바일: HUD 램프 버튼(좌하단 엄지 존), PC: `Space`
- PC: 방향키/WASD(홀드 연속) + 마우스 클릭 동일 작동
- 위 = 파낸 통로 클라이밍(느림), 좌우 = 걷기, 허공 = 낙하. 점프 없음, 가상 조이스틱 없음

## 12. HUD·UI (최소주의)

- 상단 중앙: **램프 게이지** — 가장 중요한 정보라 가장 크게. 기름 단계 하락 시 게이지 자체가 어두워짐. 램프 오프 시 게이지가 잿빛으로
- 상단 좌: 하트 / 상단 우: 가방 슬롯. 우측 가장자리: 깊이(m)
- 좌하단: 램프 토글 버튼 (터치 타깃 크게)
- 골드는 갱도에서 표시하지 않는다 (지상 정산 때만) — 갱도에서는 생존 정보만
- 거점 UI: 상인(상점) + 수첩(일지 다시 읽기·수집률)
- **오프닝 (수미상관)**: 새 세이브 첫 시작 시 3~4초 도입컷(스킵 가능) — 광부가 산 아래 도착하는 정적인 원경, 산은 그저 큰 산으로 보인다. 엔딩의 코즈믹 줌아웃이 **같은 구도를 뒤집으며** 오프닝이 복선이었음을 드러낸다. 도입컷 후 거점 도착, 상인의 한 줄 "갱도는 저쪽이야." 사망 후 '다음 광부' 시작 시에는 도입컷 없이 즉시 거점 (빠른 재시작 원칙)
- 일시정지 버튼 + 포커스 상실 시 자동 일시정지 (STARFALL 패턴 재사용)
- UI 라벨은 영어 아케이드 관용구. 서사 텍스트(일지·상인 메모·엔딩)는 **KO/EN 토글** — 타이틀·설정에서 전환, 선택은 세이브에 저장. 폰트 Galmuri 계열

## 13. 비주얼

- 기준 뷰포트 **270×480 (9:16 세로)**, `canvas_items` 스트레치, 타일 16px (화면 폭 약 16타일) — STARFALL 패턴
- 팔레트: 지표는 NEO_KIDO NIGHT 계열 → 깊어질수록 채도가 죽고 유기적인 톤으로 오염 (표토 갈색 → 심층 검붉은 맥동 발광). "내려갈수록 기괴해진다"를 팔레트 시프트로 구현
- **기괴함의 수위 — 은유 + 심층 한정 신체 연상**: 균열대까지는 '잘못된 질감' (혈관 패턴 광맥, 나이테 같은 돌결, 병든 색조). 심층부터는 명확한 신체 연상 — 이빨 같은 종유석, 심장처럼 맥동하는 광석, 숨쉬듯 미세하게 움직이는 벽 애니메이션. 피·살점 직접 묘사는 금지 (16px에서 읽히면서 전연령 안전)
- **조명이 아트의 절반**: `CanvasModulate` 암전 + 플레이어 중심 `PointLight2D` 라디얼(기름 단계별 반경 + 미세 깜빡임, 오프 시 1타일 잔광). 미탐사 타일은 완전 검정. GL Compatibility 렌더러의 2D 라이트 지원 사용
- **아트 리소스는 PixelLab 생성**: 광부(idle/걷기/클라이밍/곡괭이질/사망), '그것'(너무 큰 광부 실루엣 + 들고 있는 램프), 지층별 타일셋, 광석 7종 + 산의 심장 + 기름 병, 일지·유품·텐트 등 로어 오브젝트, 상인, 거점 소품, 타이틀 로고, 오프닝·리빌 원경 2버전(평범한 산 / 같은 구도의 숨쉬는 산맥 + 맥동 불빛). 생성 후 팔레트 톤 후처리. API 키는 `.env.local`의 `PIXELLAB_API_KEY` (잔액 확인 필요)
- 엔딩 플래시 연출은 설정에서 완화 가능 (빛 점멸 최소화 옵션)

## 14. 오디오 — VARCO Sound 생성

- **전량 VARCO Sound(NC AI) 생성으로 제작** (기존 파이썬 합성 방식 대체). Text to Sound API(`POST https://openapi.ai.nc.com/sound/varco/v1/api/text2sound`, 헤더 `OPENAPI_KEY`, 한국어 프롬프트 지원, 10초 고정 44.1kHz/16bit WAV) + Looping API(심리스 루프 변환). API 키는 `.env.local`의 `VARCO_API_KEY`. 라이선스(상업 이용 조건) 확인 후 `CREDITS.md`에 명기
- SFX: 곡괭이 타격(지층별 변주), 광석 획득, 착지, 낙석/붕괴, 램프 토글·깜빡임·기름 경고, 클라이밍, 정산, 일지 획득, 이상 현상 스팅어(에코 곡괭이·속삭임·나란한 발소리), 엔딩 각성
- 지층별 앰비언트: 표토(바람·멀어지는 새소리) → 암반(물방울·울림) → 균열대(저주파 드론) → 심층(**무음** — 발소리와 심박만) + 피날레 트랙
- '그것' 근접 = 심박 템포 가속. 화면에 보이기 전에 소리로 먼저 안다 (가짜 심박 이상 현상이 이 학습을 역이용)
- **음악은 거점에만 존재** — 갱도에 들어서면 음악이 죽고 앰비언트만 남는다 (하강 = 음악의 소멸). 지상 오염 단계(§5)에 따라 거점 음악의 음정·템포가 미세하게 틀어진다
- 모바일 햅틱: 심박·붕괴에 Vibration API (Android Chrome 한정, iOS 미지원 — 점진적 향상, 설정에서 끄기 가능)
- 포맷은 ogg, 웹 용량 예산 안에서 관리
