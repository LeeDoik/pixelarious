# DOWN THE CAVE — 게임 설계

**날짜:** 2026-08-15
**상태:** 사용자 질답으로 확정된 설계 (구현 플랜의 입력)
**대상:** NEO_KIDO 카트리지 `down-the-cave` (현재 플레이스홀더 → 실제 게임으로 교체)

## 1. 컨셉

곡괭이와 램프 하나로 내려가는 **왕복 채굴 로그라이크 호러**.

> 내려가는 건 쉽다. 문제는 올라오는 것이다.

- 카트리지 소개문("램프 기름이 떨어지기 전에 돌아올 수 있을까요?")이 그대로 게임의 정체성
- 전투 없음 — 공포는 분위기와 회피형 위협으로만. 점프스케어 없이 서서히 조여오는 드레드, 충격 연출은 최심부 엔딩 한 곳만 허용
- 모바일 필수 · 세로 화면 · 탭 조작 (NEO_KIDO 모바일 원칙 유지)

## 2. 코어 루프 (한 런)

1. **하강** — 지표 거점에서 출발. 인접 타일을 탭하면 판다/이동한다. 중력이 있어 아래로는 빠르다
2. **채굴** — 광석을 캐서 가방에 담는다 (슬롯 1개 = 광석 1개). 깊을수록 비싼 광석
3. **복귀** — 파낸 통로는 런 동안 그대로 남는다. 위로는 벽을 짚고 기어올라야 하며 하강보다 느리다 — **상승 시간 ≈ 하강의 2배** (튜닝 목표). 이 비대칭이 "돌아갈 수 있을까?"를 시스템으로 만든다
4. **정산** — 살아서 지상에 도착해야 광석이 골드로 확정. 죽으면 **가방만 잃는다** (은행 골드·업그레이드 유지 — 로그라이트)

맵은 런마다 시드를 바꿔 재생성한다. 폭 16타일 고정, 좌우 경계는 파괴 불가 경계석.

## 3. 램프 경제 — 기름 = 시간 = 안전

- 기름은 실시간으로 탄다. 잔량 단계에 따라 **빛 반경이 계단식으로 좁아진다**
- 빛은 시야이자 방어다: '그것'은 빛 안에서 움직이지 못한다(§6) → **기름 게이지가 곧 공포 게이지**
- 기름 소진 = 즉사가 아니라 최악의 생존 — 한 치 앞 어둠 속에서 기어 올라가는 이 구간이 공포의 절정
- 갱도에서 드물게 기름 병 픽업(+25%, 빈도는 튜닝). 런 시작 시 항상 만땅

## 4. 죽음 조건

| 원인 | 결과 |
|---|---|
| 3타일 초과 낙하 (장화로 완화) | 하트 1 데미지 |
| 금 간 타일 붕괴·낙석 | 하트 1 데미지 |
| '그것'에게 잡힘 | 즉사 |
| 하트 소진 | 사망 → 가방 상실, 지표에서 눈뜸 |

전투는 없다. 곡괭이는 오직 땅을 판다.

## 5. 지층 (깊이 커브 = 공포 커브, 수치는 시작값)

| 깊이 | 지층 | 광석 | 분위기 | 위협 |
|---|---|---|---|---|
| 0–40m | 표토 | 석탄·구리 | 밝은 흙, 지상의 빛, 새소리가 멀어짐 | 없음 (튜토리얼 지대) |
| 40–120m | 암반 | 철·은 | 물방울 소리, 짙어지는 어둠 | 낙석·금 간 타일. 첫 이상 현상(미묘하게) |
| 120–240m | 균열대 | 금·자수정 | 벽의 긁힌 자국, 버려진 장비 | 붕괴 잦아짐. '그것'의 기척(실체 없는 연출) |
| 240–400m | 심층 | 발광 광석 | 유기적 질감, 맥동하는 발광, BGM 소거 | **'그것' 실체 배회** |
| 400m | 최심부 | — | 엔딩 챔버 (§8) | — |

지층 경계는 곡괭이 레벨로 게이트한다(§9). 지층 진입 시 지층 이름이 잠깐 표시된다.

## 6. '그것' (Lurker) — 위핑 엔젤 규칙

- 정체: 광부의 실루엣을 한 무언가. 키가 너무 크고, 곡괭이 소리를 따라 한다
- **빛 안에서는 완전 정지. 어둠 속에서만 다가온다.** AI는 이것이 전부
- 이동은 파낸 공간으로만 — **네가 판 길이 그것의 길이다**
- 채굴 소리에 반응해 방향을 갱신한다 (캘수록 가까워진다 — 욕심의 대가)
- 닿으면 즉사. 처치·격퇴 불가. 동시 활성 최대 1개체(피날레 제외)
- 심층부터 실체 스폰(빛 반경 밖 어둠에서). 균열대에서는 연출용 기척만

## 7. 이상 현상 (AnomalyDirector)

절차 생성 위에 얹는 수작업 연출 풀. 깊이·조건 트리거, **대부분 세이브당 1회** (반복되면 공포가 죽는다):

- 램프가 2초 꺼졌다 켜진다. 아무 일도 없다 (처음엔)
- 파고 내려온 통로가 등 뒤에서 메워져 있다
- 곡괭이질 에코가 한 박자 늦게 두 번 울린다
- 화면 가장자리를 실루엣이 지나간다 (빛 밖에서)
- 캐낸 광석 자리에서 속삭임이 들린다
- 지상 상인이 자리에 없고 메모만 있다 (다음 런에 복귀)

풀은 지층별로 강도를 높여 배치. 구현 시 이벤트 추가가 쉬운 데이터 주도 구조로.

## 8. 엔딩 — 산의 심장

- 400m 최심부 챔버 중앙에 맥동하는 거대 발광 광석 **'산의 심장'**
- 심장을 캐는 순간 (유일하게 허용된 충격 연출) 모든 빛이 죽고 산 전체가 깨어난다
- **피날레**: 심장의 맥동이 유일한 광원 — 펄스가 밝아지는 동안만 그것들이 멈춘다. 깨어난 그것들 사이로 400m를 기어오르는 원테이크 탈출
- 탈출 성공 → 진엔딩 + 크레딧. 실패 → 산은 다시 잠들고 지표에서 눈뜸, 다음 런에서 재도전 가능

## 9. 이코노미·업그레이드 (시작값, 튜닝 대상)

광석 가치: 석탄 5 / 구리 10 / 철 25 / 은 50 / 금 100 / 자수정 150 / 발광 광석 300 G

| 트랙 | 효과 |
|---|---|
| 곡괭이 Lv1–4 | 더 단단한 지층 채굴 가능(**지층 게이트**) + 채굴 속도 |
| 램프 Lv1–4 | 기름 용량 = 잠수 가능 시간 |
| 가방 Lv1–4 | 슬롯 8 → 12 → 16 → 20 |
| 장화 Lv1–3 | 낙하 허용 3 → 4 → 5타일 |
| 헬멧 Lv1–3 | 하트 3 → 4 → 5 |

- 구매는 지표 거점의 상인. 비용 커브 기준: "런 2~3번이면 다음 한 칸"
- 골드·업그레이드·이상현상 이력·엔딩 플래그·설정은 `user://` 세이브 (웹 IndexedDB). 런 중간 세이브는 없다

## 10. 조작

- **인접 4방향 타일 탭** — 벽이면 판다, 빈 곳이면 이동. **길게 누르면 연속 동작**. 비인접 탭은 무시
- PC: 방향키/WASD(홀드 연속) + 마우스 클릭 동일 작동
- 위 = 파낸 통로 클라이밍(느림), 좌우 = 걷기, 허공 = 낙하. 점프 없음, 가상 조이스틱 없음

## 11. HUD·UI (최소주의)

- 상단 중앙: **램프 게이지** — 가장 중요한 정보라 가장 크게. 기름 단계 하락 시 게이지 자체가 어두워짐
- 상단 좌: 하트 / 상단 우: 가방 슬롯. 우측 가장자리: 깊이(m)
- 골드는 갱도에서 표시하지 않는다 (지상 정산 때만) — 갱도에서는 생존 정보만
- 일시정지 버튼 + 포커스 상실 시 자동 일시정지 (STARFALL 패턴 재사용)
- UI 라벨은 영어 아케이드 관용구, 서사 텍스트(상인 메모·엔딩)는 한국어. 폰트 Galmuri 계열

## 12. 비주얼

- 기준 뷰포트 **270×480 (9:16 세로)**, `canvas_items` 스트레치, 타일 16px (화면 폭 약 16타일) — STARFALL 패턴
- 팔레트: 지표는 NEO_KIDO NIGHT 계열 → 깊어질수록 채도가 죽고 유기적인 톤으로 오염 (표토 갈색 → 심층 검붉은 맥동 발광). "내려갈수록 기괴해진다"를 팔레트 시프트로 구현
- **조명이 아트의 절반**: `CanvasModulate` 암전 + 플레이어 중심 `PointLight2D` 라디얼(기름 단계별 반경 + 미세 깜빡임). 미탐사 타일은 완전 검정. GL Compatibility 렌더러의 2D 라이트 지원 사용
- **아트 리소스는 PixelLab 생성**: 광부(idle/걷기/클라이밍/곡괭이질/사망), '그것', 지층별 타일셋, 광석 7종 + 산의 심장 + 기름 병, 상인, 거점 소품, 타이틀 로고. 생성 후 팔레트 톤 후처리. API 키는 `.env.local`의 `PIXELLAB_API_KEY` (잔액 확인 필요)
- 엔딩 플래시 연출은 설정에서 완화 가능 (빛 점멸 최소화 옵션)

## 13. 오디오 — Vacro AI 사운드 생성

- **전량 Vacro AI 사운드 생성으로 제작** (기존 파이썬 합성 방식 대체). 라이선스(상업 이용 조건) 확인 후 `CREDITS.md`에 명기, 생성 파이프라인·키 관리는 구현 플랜에서 확정
- SFX: 곡괭이 타격(지층별 변주), 광석 획득, 착지, 낙석/붕괴, 램프 깜빡임·기름 경고, 클라이밍, 정산, 이상 현상 스팅어(에코 곡괭이·속삭임), 엔딩 각성
- 지층별 앰비언트: 표토(바람·멀어지는 새소리) → 암반(물방울·울림) → 균열대(저주파 드론) → 심층(**무음** — 발소리와 심박만) + 피날레 트랙
- '그것' 근접 = 심박 템포 가속. 화면에 보이기 전에 소리로 먼저 안다
- 포맷은 ogg, 웹 용량 예산 안에서 관리

## 14. 기술 아키텍처

- 신규 `games-src/down-the-cave/` — Godot 4.7.1 Standard(GDScript), gdUnit4 하네스 동일 패턴 (`$GODOT = C:\Users\LeeDoik\tools\godot\godot_console.exe`)
- 오토로드: `GameState`(세이브·은행·업그레이드·플래그), `Sfx`
- 씬: `Main`(거점 ↔ 갱도 상태 머신), `Surface`(거점·상인), `Mine`(TileMapLayer), `Player`, `Lurker`, `HUD`, `AnomalyDirector`
- **순수 함수 코어** (`src/core/`): `worldgen.gd`(시드 절차 생성 — 지층 분포·광석/기름 배치), `economy.gd`(광석 가치·업그레이드 커브·정산), `oil.gd`(소모율·빛 반경 단계), `lurker_logic.gd`(빛 정지·어둠 접근·소리 반응 스텝), `anomaly_pool.gd`(트리거 조건·1회성)
- 웹 익스포트: Web 프리셋, 스레드 비활성화(COOP/COEP 불필요), `web/shell.html` 재사용 → `public/games/down-the-cave/`
- 사이트 등록: `content/games/02-down-the-cave.json`에 `playPath: "/games/down-the-cave/index.html"`, 태그를 `GODOT 4, 2D, ROGUELIKE, HORROR, MOBILE OK`로 교체. 소개문은 현행 유지 (이미 확정 기획과 일치)

## 15. 테스트 전략

- gdUnit4 헤드리스: `worldgen`(시드 재현성·지층별 타일/광석 분포), `lurker_logic`(빛 안 정지·어둠 접근·소리 반응), `economy`(가치·커브·정산·사망 시 가방 상실), `oil`(단계 경계·소진 상태), `anomaly_pool`(트리거·1회성 보장)
- 사이트 vitest 기존 스위트 통과 확인 (games.ts 스키마)
- 수동 플레이테스트 체크리스트: `docs/superpowers/specs/down-the-cave-playtest.md` — 데스크톱 + 모바일 실기, 터치 조작감·조명 성능·공포 페이싱 점검

## 16. 성공 기준

- 모바일 브라우저에서 터치만으로 엔딩까지 온전히 플레이 가능
- 첫 런을 설명 없이 이해 (첫 조작이 곧 튜토리얼)
- 평균 런 3–6분, 엔딩 도달 1~2시간, 30fps 이상
- gdUnit4·vitest 전부 통과, 프로덕션 배포 후 카트리지에서 PLAY 동작

## 17. 하지 않는 것 (YAGNI)

- 전투 시스템, 크래프팅/조합
- NPC 대화 트리 (상인은 상점 UI + 짧은 메모만)
- 리더보드·일일 시드, 분기 바이옴, 다회차 뉴게임+
- 게임패드 지원, PWA 오프라인
