# 스크린샷 원본 캡처

여기에 **실제 플레이 화면** 캡처를 넣고 `python scripts/gen_store_assets.py`를 실행하면
1280×800 스토어 스크린샷이 합성된다. 스토어 규정상 실제 화면이어야 하므로 합성 재현은 쓰지 않는다.

| 파일 | 담을 장면 |
| --- | --- |
| `01-title.png` | 타이틀 / 첫 궤도 진입 |
| `02-combo.png` | 콤보가 쌓인 플레이 중 화면 |
| `03-gameover.png` | 게임 오버 + 최고 점수 |

- 비율은 게임 원본과 같은 세로(270×480 계열). 브라우저 창을 좁게 줄여 캡처하거나
  DevTools 기기 툴바에서 270×480으로 맞춘 뒤 캡처하면 된다.
- 이 폴더의 캡처 자체는 스토어에 올리지 않는다. 업로드용은 `../screenshot-*-1280x800.png`.
